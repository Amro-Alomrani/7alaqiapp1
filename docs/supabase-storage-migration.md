# مساحة الصور على Supabase مع إبقاء Firebase

المشروع يستخدم Firebase Auth وFirestore للحسابات والحجوزات، وSupabase Storage لرفع الصور الجديدة. وسيط الصور منشور باسم `media` على Supabase Edge Functions، ضمن خطة Supabase المتاحة. لا يتطلب وسيط الصور تفعيل Blaze في Firebase.

## الإعدادات العامة للتطبيق

- `VITE_SUPABASE_URL=https://vjeuesqrzywragnjvkpi.supabase.co`
- `VITE_SUPABASE_PUBLISHABLE_KEY` = المفتاح العام المخصص للعميل.
- `VITE_SUPABASE_PUBLIC_MEDIA_BUCKET=halaqi-media`
- `VITE_SUPABASE_PRIVATE_CHAT_BUCKET=halaqi-chat`

توضع هذه القيم في بيئة البناء أو `.env.local` المتجاهل بواسطة Git. لا يوضع مفتاح Supabase سري داخل `VITE_*` أو في حزمة Android.

## مسار الرفع والقراءة

1. يسجل العميل الدخول عبر Firebase كما كان.
2. يرسل إثبات Firebase إلى وسيط `media`. يتحقق الوسيط من الرمز وحالة الحساب لدى Google، ومن أذونات الحجز عبر Firestore قبل الوصول إلى الصور الخاصة.
3. يصدر الوسيط إذن رفع موقّعًا لملف واحد ضمن مجلد المالك. الملف نفسه ينتقل مباشرةً إلى Supabase Storage، بحد أقصى 10 MB وصيغة صورة.
4. صور الحسابات والصالونات والمنشورات في `halaqi-media` قابلة للقراءة العامة مثل قواعد الصور السابقة. صور محادثات الحجز في `halaqi-chat` خاصة، ولا يصدر رابطها المؤقت إلا لطرفَي الحجز.
5. يحتفظ Firestore بعلامة `supabase-storage://` للصورة الخاصة. واجهة المحادثة تطلب رابطها عند العرض وتجدده قبل انتهاء الصلاحية.

يستخدم وسيط Supabase اعتماد الخادم الداخلي في بيئة Edge. المفتاح الذي قُدّم لتهيئة البكتين لا يوضع في التطبيق ولا يحتاجه العميل بعد نشر الوسيط.

## النشر

بعد تسجيل الدخول إلى Supabase CLI:

```powershell
supabase functions deploy media --project-ref vjeuesqrzywragnjvkpi --use-api
```

تضبط `supabase/config.toml` مدخل الوظيفة و`verify_jwt=false` لأن رمز المستخدم صادر من Firebase؛ `handler.ts` ينفذ التحقق الفعلي بواسطة Google قبل أي عملية تخزين. لا توجد عملية رفع أو قراءة خاصة مجهولة الهوية، ولا سياسات RLS تمنح العملاء كتابة مباشرة.

ملف `supabase/migrations/202610280001_storage.sql` يصف البكتين ويزيل سياسات المسودة السابقة إن كانت طُبقت. لا يحتاج المسار الحالي تكامل Firebase Third-Party Auth في Supabase ولا جدول عضوية حجز مكررًا.

## الصور القديمة وحذف الحساب

روابط صور Firebase القديمة تبقى كما هي. لا ينسخ هذا التغيير الصور القديمة تلقائيًا. تمت إضافة تنظيف ملفات Supabase المتداخلة إلى مصدر دالة حذف الحساب في Firebase؛ نشر دوال Firebase يظل يحتاج خطة Blaze. لا تعتبر حذف الحساب مكتملًا على الإنتاج حتى تُنشر الدالة وتُختبر على حساب اختبار فعلي.

بعد إتمام النشر والاختبارات، ألغِ المفتاح السري الذي ظهر في المحادثة. بيانات دخول CLI والمفاتيح المحلية ليست ضمن ملفات Git.
